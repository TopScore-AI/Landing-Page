Accessibility

Built to be usable by every student.

TopScore AI is a learning tool, so the standard we hold ourselves to is the standard a teacher would hold themselves to: every student, in every classroom, with whatever device or support they have, should be able to learn.

What we do

  • Keyboard-friendly navigation. Every interactive element is reachable with the Tab key, with a visible focus ring so you always know where you are.
  • Screen-reader support. All images have descriptive alternative text. The mobile menu uses proper aria-expanded and aria-controls attributes, and the FAQ accordion uses native <details> elements so it works with assistive tech out of the box.
  • Respects reduced motion. If your device is set to reduce motion, every animation and scroll-reveal effect is disabled automatically.
  • Mobile-first design. Every layout works on a five-inch screen, including the navigation, the app showcase, and the pricing table.
  • Offline-friendly. The site registers a service worker so the page is reachable on patchy connections, and the resource library inside the app is built to work offline.
  • Clear, readable typography. Body text uses a minimum 16px base size, with line-height tuned for sustained reading.

Known gaps

We're honest about what we haven't finished yet:

  • The marketing site is in English only. A Swahili version is on the roadmap. The in-app tutor already supports Swahili.
  • Some diagrams in the resource library are images rather than live SVG. We're working through them to add text alternatives where the image is the only carrier of meaning.
  • We don't yet have a formal audit against WCAG 2.2 AA from a third party. Internal checks against the WCAG quick-reference guide are in place; an external audit is planned for 2026.

Tell us when we get it wrong

If something on this site or in the app is hard to use with your setup, please tell us — a one-line email is enough. The fastest way to reach a human is admin@topscoreapp.ai or WhatsApp 0717 273 230. We read every message and prioritise accessibility reports first.

Standards we work against

The site is built against the Web Content Accessibility Guidelines (WCAG) 2.2, with the goal of meeting AA conformance. The app is built against the Material Design accessibility guidelines, which align with WCAG.
